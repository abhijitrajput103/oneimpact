# One Impact — Full-Service Creative & Digital Growth Agency

One Impact is a modern, high-performance web application and digital presence for a full-service creative agency. Built with cutting-edge web technologies, the platform delivers an immersive, neo-editorial visual experience that showcases agency capabilities, case studies, client partnerships, and creative disciplines.

---

## Agency Overview & Core Capabilities

One Impact delivers integrated creative and growth solutions designed to build memorable brands, generate sustained market demand, and achieve measurable business results:

- **Search Engine Optimization (SEO)**: Data-led search strategy, technical site architecture, conversion-rate optimization (CRO), app store optimization (ASO), and authority building.
- **Social Media Marketing (SMM)**: Community-first brand development, viral social campaigns, audience engagement systems, and cross-platform distribution.
- **Influencer Marketing & Creator Alliances**: Strategic talent matching, authentic influencer campaigns, performance tracking, and creator-led brand collaborations.
- **Branding & Visual Identity**: Distinctive design systems, typography guidelines, brand positioning, storytelling, and comprehensive identity kits.
- **Web Development & Digital Architecture**: Custom high-speed digital experiences, bespoke animations, modern responsive interfaces, and enterprise-grade web engineering.

---

## Technical Stack & Architecture

- **Application Framework**: Next.js (App Router architecture with React Server Components)
- **UI & State Layer**: React 19 with strict TypeScript typing
- **Styling Architecture**: Tailwind CSS v4 with modular CSS modules for isolated micro-interactions
- **Motion & Physics Engine**: GSAP (GreenSock Animation Platform) paired with ScrollTrigger
- **Scroll & Inertia Engine**: Lenis smooth scroll for fine-pointer desktop navigation with native compositor-thread scrolling on mobile touch devices
- **Asset Pipeline**: Next-generation WebP and AVIF image pipeline with alpha transparency support
- **Font Optimization**: Google Fonts delivered via Next.js variable font optimization with zero layout shift
- **Communication Infrastructure**: Dedicated serverless inquiry API endpoint with honeypot security and payload validation

## Performance & Optimization Standards

- **Asset Efficiency**: All raster graphics are pre-converted to high-efficiency WebP/AVIF formats, eliminating heavy legacy formats.
- **Mobile-First Responsiveness**: Tailored mobile layouts utilizing native high-refresh touch scrolling and hardware-accelerated canvas components.
- **Immutable Caching**: Long-term static asset caching headers applied across all media, fonts, and scripts.
- **Accessibility & Motion Preferences**: System-level reduced-motion detection honoring user preferences across all GSAP and scroll behaviors.

## Getting Started

To run and preview the project locally:

1. Install project dependencies using standard package managers (`npm`, `pnpm`, or `yarn`).
2. Run the development server to preview the site locally on port 3000.
3. Use the built-in image optimization tool (`npm run optimize-images`) to compress any new media added to the public folder.
4. Build the production bundle using the standard build command to generate static pages and optimized artifacts.

---

## Production Deployment

The project is structured for zero-configuration deployment to edge infrastructure providers such as Vercel or modern Node.js server environments. Ensure required email API keys are configured in your deployment environment variables before publishing the contact workflow.
